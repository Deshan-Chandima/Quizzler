# Quizzler

Quizzler is an Android application that allows users to **create
quizzes**, **answer quizzes**, **download quizzes**, and **complete them
with a timer**. It is designed to be simple, fast, and easy to use.

## ✅ What Quizzler Does

-   Create your own quizzes by adding questions and answers.
-   Take quizzes and receive instant scoring.
-   Download external quizzes and play them.
-   Timer-based quiz system to make attempts more challenging.
-   All quizzes are saved locally on the device.

## 📥 How to Install

1.  Download or clone the project:

        git clone https://github.com/Deshan-Chandima/Quizzler.git

2.  Open the project in **Android Studio**.

3.  Let Gradle sync automatically.

4.  Connect an Android device or start an emulator.

5.  Click **Run ▶** in Android Studio.

## ▶️ How to Run the App

1.  After installing, open **Quizzler** on your device/emulator.
2.  Choose from the main menu:
    -   **Create Quiz** → Add questions, answers, and correct choices.
    -   **Play Quiz** → Select a quiz and answer questions.
    -   **Download Quiz** → Import quiz files from storage.
3.  When you start a quiz:
    -   A **timer** begins counting down.
    -   Select your answers before time runs out.
    -   Your final score is shown at the end.

## 📝 Quiz Creation

Each custom quiz supports:  Multiple choice questions,  Four answer
options per question , One correct answer  ,Automatic score calculation, Timed attempts

## 📂 Project Structure

-   `app/src/main/java/`  Main Java source code
-   `app/src/main/res/layout/` XML UI layout files
-   `app/src/main/res/values/`  Strings, colors, styles
-   Local quiz files stored inside the app's directory
